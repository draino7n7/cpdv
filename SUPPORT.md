# Support

If you need help using the CPDV JSON files in your application, regenerating the corpus, or running the verification suite, please check the following resources:

1.  **README:** Start by reading [`README.md`](README.md) for schema documentation, book/chapter/verse structure (including Prologue `"P"` chapters), and CLI usage.
2.  **Agent & Maintainer Guide:** Review [`AGENTS.md`](AGENTS.md) for technical details on source HTML quirks and verification checks.
3.  **Issues:** Search existing [GitHub Issues](https://github.com/draino7n7/cpdv/issues) to see if your question or problem has already been addressed.
4.  **Create an Issue:** If you cannot find an answer, open a new issue and include your OS, Python version, and any command output.

Please note that this is a public-domain project maintained by volunteers (and AI agents), so response times may vary.
