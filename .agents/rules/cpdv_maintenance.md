# CPDV Corpus Maintenance & Verification Rules

**CRITICAL DIRECTIVES FOR ALL AGENTS:**

1. **NEVER HAND-EDIT GENERATED JSON FILES**: All 73 `CPDV-JSON/*.json` book files, `CPDV-JSON/EntireBible-CPDV.json`, and `CPDV-JSON/books.json` are generated by `src/encode_cpdv.py`. Make changes in `src/encode_cpdv.py` and regenerate.
2. **ALWAYS RUN `src/verify_cpdv.py`**: After any change to `src/encode_cpdv.py`, `src/CPDVJSONEncoder.groovy`, or `CPDV-JSON/*.json`, you MUST run `python src/verify_cpdv.py` and confirm 0 errors across all 73 books, 1,335 chapters, and 35,839 verses.
3. **PRESERVE BACKWARD COMPATIBILITY**: Downstream projects (including `PrayTheRosary`) rely on the existing filenames (`CPDV-JSON/OT-01_Genesis.json`, `CPDV-JSON/EntireBible-CPDV.json`) and object keys (`"Genesis"`, `"1-Samuel"`, `"Song2"`, `"charset": "UTF-8"`). Never rename or remove existing keys.
4. **ZERO THIRD-PARTY PYTHON DEPENDENCIES**: Keep `src/encode_cpdv.py` and `src/verify_cpdv.py` strictly limited to the Python 3 standard library so they run out of the box in any environment or CI runner.
