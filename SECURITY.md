# Security Policy

## Supported Versions

Only the latest commit on the default branch (`master`) is actively maintained and supported with updates.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within the encoding/verification scripts or CI workflows in this project, please **DO NOT** create a public GitHub issue.

Instead, please privately report it by using GitHub's [Private Vulnerability Reporting / Security Advisories](https://github.com/draino7n7/cpdv/security/advisories) feature or contacting the repository maintainer directly.

We will attempt to respond to your report within 48 hours and provide an estimated timeline for the fix.
